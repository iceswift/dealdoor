# DealDoor — Product Plan

> ดีลไหนดี — หน้าโปรโมชันร้านค้า แชร์ง่าย หมดอายุเอง พร้อมแผนที่และช่องทางติดต่อ

---

## 1. Product Summary

| Field | Value |
|-------|-------|
| Name | DealDoor |
| Thai Name | ดีลไหนดี |
| Type | Local commerce promotion page platform |
| Core Concept | Linktree for local shop deals |
| Target Market | Thailand (initial) |
| Primary Users | Local merchants + their customers |

---

## 2. Problem Statement

Local shop promotions are scattered across Facebook posts, LINE broadcasts, IG stories, TikTok captions, and printed signs. Customers cannot tell which deals are active. Shops forget to remove expired deals. There is no single structured page for a shop's current promotions.

---

## 3. Solution

A shareable deal page for each shop. One link that shows:
- Active deals with expiration dates
- Shop location with map
- Contact channels (LINE, phone, Facebook)
- Menu or product catalog
- Share/copy code actions

---

## 4. MVP Scope

### In Scope (MVP)
1. **Public Shop Deal Page** — the core product
2. **Merchant Dashboard** — create shop, manage deals
3. **Basic Explore Page** — browse sample deals

### Out of Scope (MVP)
- Real payment system
- Complex authentication
- Marketplace ranking algorithm
- Real-time chat
- Delivery system
- E-commerce checkout
- Loyalty points
- Review system
- Mobile app

---

## 5. User Flows

### 5.1 Merchant Flow
```
Open DealDoor → Create shop page → Enter shop info → Add deals →
Preview page → Copy link → Share on LINE/FB/IG/TikTok/QR
```

### 5.2 Customer Flow (from shared link)
```
Receive link → Open shop page → See active deals → Check expiration →
Copy code / Contact LINE / Open map / Call shop → Visit shop
```

### 5.3 Customer Discovery Flow
```
Open Explore → Search/filter → See deal cards → Open shop page →
Claim/save/share deal
```

---

## 7. Free vs Paid Tier

### Free Tier
- 1 shop page
- Max 6 active deals
- Basic shop info
- Basic menu/catalog
- Basic map preview
- Shareable link

### Paid Tier (Coming Soon placeholders)
- Unlimited deals
- Multiple branches
- Custom branding
- Analytics
- Coupon tracking
- QR code tools
- Featured placement

---

## 8. Success Criteria

1. Merchant can create a shop page in under 5 minutes
2. Customer can understand a deal within seconds of opening the page
3. Expired deals are clearly handled
4. Page looks good on mobile
5. Shop page is shareable via link
6. Product is useful even with only 1 shop

---

## 9. Monetization Model

**Merchant SaaS / Freemium**

Start by giving merchants better tools to organize and share promotions. Do not promise marketplace traffic initially.

> "We help you organize and share your promotions better."

Discovery and promotion features come after enough merchant pages exist.
